# Rows stop at the top and bottom

Up on Home's first row went round to the last row (and Down on the last to the first): Kodi's
grouplist wraps when it has nowhere set to go. Holding a remote's Up or Down cycled through every
row. The owner asked for it to stop.

## What changed

- Home's rows (`skin/script-arc-home.xml`), a library's Recommended rows, a person's page and
  search's results now say where Up and Down go at their ends: nowhere (`noop`), as the title page
  already did. Up on the first row and Down on the last stay put; the sidebar is still Left.
  Recommended's Up still goes to the tabs.

## Checked

- `python3 -m pytest -q`: 95 passed. `python3 tools/check.py`: all good.
- Kodi 20 on a virtual display against a scratch Arc (not real hardware): Home, eight quick Ups
  from the first row stayed on it; twelve quick Downs stopped on the last row, and more Downs
  kept it there; Up from there moved one row as before.
