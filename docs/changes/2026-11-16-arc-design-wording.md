# "Arc's design", not "the Apple TV app's"

The README's title-page heading now says the pages are in Arc's design rather than "like Arc's
Apple TV app" (owner, 16 November): the TV apps share one Arc design, and the README shouldn't
present this app as a copy of another. Code comments that name the arc-apple file a screen was
matched to are kept, since they tell developers where to look.
