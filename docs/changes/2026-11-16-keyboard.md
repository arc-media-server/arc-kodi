# Arc's own keyboard

Typing the server address, the household password and a Watch Together code opened Kodi's own
keyboard, drawn by the user's skin. The owner asked for Arc's own, so they match the rest of Arc.

## What changed

- A keyboard window (`kodi/windows/keyboard.py`, `script-arc-keyboard.xml`; the pages and editing
  are `arc/keyboard.py`, tested): what to type at the top, the text typed so far in a field (a
  password as dots), the keys ten across in Arc's key style (as Search's), and under them Shift,
  123 / ABC, Space, Delete, Clear and Done.
- Three pages: small letters, capitals, and digits and symbols. The letters' last row has `. - _ @`
  (addresses and emails); the symbols page has `/ :` for an address with a port or https://.
- A server address and a password open on small letters; a Watch Together code (capitals and
  digits, as Arc makes them) on capitals. A remote's number keys type digits.
- Done returns what was typed; Back closes it without doing anything.
- Used for: the server address (first screen and Use Another Server), Sign In with Password, and
  Join with a Code (Settings).

Not done: typing on a computer keyboard. Kodi gives an add-on window typed characters only
through its text-field control, which opens Kodi's own keyboard on OK, so the keyboard is for
the remote. (Search keeps its text field, so a computer keyboard still types there.)

## Logging

Nothing new; a failure to draw the window is logged as an error. What's typed is never logged.

## Checked

Kodi on Xvfb against a scratch Arc: Join with a Code (typed ABC73, Done: Arc answered 404, the
"didn't work" message); Use Another Server (typed 127.0.0.1:8199 with the number keys and the
symbols page, Done connected and showed the sign-in code); Sign In with Password (four
characters shown as dots, Back sent nothing). Signed in again by approving the code. Not on
real hardware.
