# A README like the server's

The owner asked for the README to have the server repository's feel, with screenshots.

- The stacked logo (black, or white in dark mode: `docs/brand/`, copied from the server's
  `docs/brand`), a one-line tagline and badges (status, licence, Kodi 19+, Python 3.8+, no
  dependencies), as the server's README.
- A large Home screenshot, then pairs: a film's page, a show's page, a library, search, Watch
  Together and Settings; sign-in and the profile picker further down.
- What it does, in the server README's style (an emoji and a bold lead per point), then
  Installing, Playback (the 13 November policy: Kodi handles decoding, HDR, Dolby Vision and
  passthrough), For developers and Licence.

The screenshots (`docs/screenshots/`, 1600 wide JPEGs, 1.3 MB together) are real Kodi on a
virtual display against a scratch Arc with the server's test library. The player isn't shown:
the test library's clips are colour bars, which don't show it well.
