# Pre-roll before movies

Initial movie plays from the beginning fetch the configured pre-roll list and play it in order
before the movie. Resume, Watch Together and automatic queue advancement skip this step. An
empty/failed/malformed list or the three-second list deadline falls through to the movie; late
list results cannot change playback. Unsupported clips advance, and each focused bottom-right
Skip advances one clip. Back/Stop exits the entire attempt, including an open that completes late.

Use the existing player/Skip control and existing cast API. Native clip playback requires server
PR arc-media-server/arc-media-server#485; the client hands over only scoped playback links, never
session credentials. Client/server handoff: server docs/PREROLL-CLIENTS.md. No new setting/screen.

Kodi may report an unreadable clip as Stopped rather than Error. Advance on that failure while
ignoring the old source's stop when Skip replaces it. Dismiss Kodi's optional-clip error dialog
only during pre-roll; normal movie errors remain visible. Late cancelled clip starts stop only
that clip's exact URL, preserving other playback. Clips do not write movie progress.
